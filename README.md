# OpenClash / Mihomo 高级分流配置模板

本配置专为 **OpenClash / Mihomo (Clash.Meta)** 定制。设计遵循“订阅直挂切片、业务与节点解耦、动静结合调度、规则分层拦截”原则，适用于日常办公、流媒体解锁、AI 工具、跨境电商多店铺及金融账户防风控等场景。

## 三、特色业务策略组详解

### 1. 人工智能 (AI)
* **ChatGPT**：屏蔽香港节点，默认分配南洋、欧美及日韩节点，避免触发地区封锁。
* **AI服务**：分配给 Claude、Gemini、Copilot 等境外 AI 服务。

### 2. 跨境电商运营
* **虾皮电商 (Shopee)**：专门挂载菲律宾、马来西亚、新加坡、泰国、印尼、越南测速组，支持直连，防止多站点混用同一出口引发风控。
* **Amazon**：专选美、日、英、德、港等主流站点，避免因节点漂移导致账号审核。
* **国外电商**：承接 eBay、AliExpress 等海淘及跨境购物网站。

### 3. 金融与电子钱包
* **金融银行**：
  * 国区 `paypal.cn` 强制走直连；
  * 国际版 PayPal 和 Wise 限制在固定国家（美/港/新/菲/英/日）或直连，避免异地 IP 剧烈波动触发风控。

### 4. 社交与流媒体
* **TikTok**：剔除中国香港节点，路由至南洋、美、日、新等合规区域。
* **Bahamut (动画疯)**：仅分配台湾、香港节点及直连。
* **国外主流视频 / YouTube**：覆盖 Netflix、Disney+、HBO 等，支持大区自动测速。

## 四、规则匹配顺序 (Rules Hierarchy)

配置文件按自上而下的严格顺序执行：

1. **私有网络**：局域网 IP 与设备直连（DIRECT）。
2. **AI 服务**：OpenAI 及其它境外 AI 规则优先截流。
3. **国区游戏与下载**：国内 CDN、BT/PT 做种直连，避免消耗机场流量。
4. **常用服务**：即时通讯、社交媒体、GitHub、Steam、流媒体等精准匹配。
5. **跨境电商**：Shopee 与 Amazon 规则置顶，避免被后续通用规则误伤。
6. **金融服务**：PayPal 与 Wise 全链路集中收敛。
7. **GFW 代理兜底**：阻断名单流量进入手动选择。
8. **GEOIP IP 分流**：针对 Telegram、Google、Netflix 等未解析 IP 进行识别。
9. **大陆白名单**：国内域名与大陆 IP 走全球直连。
10. **漏网之鱼**：未命中规则的所有境外流量兜底接管。

## 五、使用建议

1. **内核要求**：推荐使用 **Mihomo (Clash.Meta)** 内核。
2. **替换订阅**：找到配置中的 `Provider_123456`，将其中的 `url` 修改为你自己的机场订阅链接。
3. **更新规则**：定期在控制面板中更新 `geoip` 与 `geosite` 规则数据库以获得最佳体验。
